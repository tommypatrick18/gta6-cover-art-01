VICE HEAT — Cover Studio: turn your own photos into a GTA-style cover poster. Pick a wanted level (1–5) and the poster rebuilds itself — panel count, grade heat, title scale and tagline all follow the level. Face-aware crops, six sunset grades, and one-click PNG export in 1080×1080, 1080×1350 and 1920×1080.

## Run it

```sh
cd app && python3 -m http.server 8000
```
